Rclone Drive Backup Privacy Policy

The backup uses Google Drive file names, folder information, and file metadata to compare local files with existing backups. It uploads new or changed backup files to the owner’s Google Drive. Rclone stores its authorization credentials on the owner’s Mac so the backup can run on a schedule.

The backup does not sell Google user data or use it for advertising. It does not send that data to any service other than Google Drive. The owner can revoke access in their Google Account and remove backups from Google Drive.
